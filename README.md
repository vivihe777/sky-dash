# Sky Dash · 天空冲刺 🎮

> A Flappy Bird-style browser game — 10 levels, 3 skins, zero dependencies.

**[▶ Play Now](https://your-project.vercel.app)**

## Features

- 🐦 3 fully hand-drawn skins (Classic Bird · Cyber Mech · Ghost Spirit)
- 🏆 10 progressive levels (speed, gap width, moving pipes, wind force)
- 🪙 In-level coin collection + star rating
- 📱 Mobile touch + PC keyboard (Space / ↑) support
- ⚡ 60fps, single HTML file, zero dependencies

## Level Progression

| Level | Title | Mechanics |
|-------|-------|-----------|
| 1–4   | 新手→急速 | Speed & gap increase |
| 5     | 狂风挑战 | Wind force added |
| 6–7   | 移动迷宫 | Moving pipes |
| 8–10  | 双重→终极 | Wind + moving pipes combined |
